# Neema Task Management

A simple task management application built to help users create, view, update, delete, search, filter, and track tasks.

## Features

* Create new tasks
* View all tasks
* Update task status
* Delete tasks
* Search tasks by title
* Filter tasks by completed or pending status
* View task statistics
* Save tasks using browser localStorage
* Confirmation dialogs for important actions
* Success and error notifications
* Responsive web interface

## Technologies Used

## How to Run the Web Application

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a web browser.
3. The Task Management application will be displayed in the browser.

##  to Run the Node.js Application


Open the terminal inside the project folder and run:

```bash
node app.js
```

The application provides options for:

1. Create Task
2. View Tasks
3. Update Task
4. Delete Task
5. Search Task
6. Filter Tasks
7. Task Statistics
8. Exit

## Task Status

Each task can have one of two statuses:

* Pending
* Completed

Users can update the status of a task when the task is completed.

## Task Statistics

The application can display:

* Total Tasks
* Completed Tasks
* Pending Tasks

## Git and GitHub Workflow

This project was developed using a feature-branch workflow.

The project includes multiple feature branches, pull requests, and merged changes.

* `feature/search-filter`
* `feature/task-statistics`
